# picknet

Pick CSV/TSV net tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/picknet/

## Install / run

```bash
git clone https://github.com/theworker02/picknet.git
cd picknet
node src/cli.js
node --test
```
